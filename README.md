# 社宅 SOP 知識庫

新北市住宅及都市更新中心的社宅 SOP 線上教學網站。中心同仁和物業管理單位可以在這裡：

- **看懂作業流程**：依時間點分階段呈現，可以切換對照「原始流程圖」
- **線上填寫**：檢核表、報告表、事件表可以直接在網頁上勾選或輸入
- **下載回傳**：下載的 Word 檔就是原始文件，只把填寫內容寫進去，格式完全相同

> 線上網址：`https://<帳號>.github.io/<repository 名稱>/`（開啟 GitHub Pages 後生效）

支援深色模式、手機瀏覽、鍵盤操作。動畫使用 [CSS Animations 100](../CSS動畫庫)。

## 檔案結構

```
├─ index.html              網站入口（只有這一頁，用 #/章節/子頁/文件 切換）
├─ favicon.ico
├─ files/                  ★ 原始文件：直接複製「2.資料庫」的資料夾結構
│  └─ NC-01(緊急事故通報相關)/NC-01-01(颱風暨豪雨相關)/…
├─ data/
│  ├─ catalog.js           ★ 網站目錄：章節、子頁、文件清單（新增章節改這裡）
│  ├─ flows.js             作業流程圖檢視器設定（圖片路徑、可點擊的文件熱區座標）
│  ├─ docs/<文件編號>.js   Word 文件內容（由 tools/build_data.py 產生，文字逐字取自原檔）
│  └─ templates/<編號>.js  可填寫表單的原始檔（下載已填寫版本時使用）
├─ assets/
│  ├─ css/site.css         網站樣式
│  ├─ css/motion-lib.css   CSS Animations 100 動畫庫
│  ├─ js/app.js            網站主程式
│  ├─ js/docx-filler.js    把填寫內容寫回原始 .docx
│  ├─ js/motion-helpers.js 動畫小工具（含吉祥物視線跟隨）
│  ├─ js/vendor/jszip.min.js
│  ├─ img/flows/           原始流程圖圖片
│  └─ dijia.svg、favicon…  吉祥物「抵家」與網站圖示
├─ tools/build_data.py     文件資料產生器
├─ README.md、CHANGELOG.md、.gitignore、.nojekyll
```

## 頁面層級

```
首頁 › NC-01 緊急事故通報相關 › NC-01-01 颱風暨豪雨相關 › 文件
```

每一頁上方都有路徑（麵包屑）。子頁裡一個文件對應一個切換按鈕，文件的最上方和最下方都有「下載原始文件」。

## 文件呈現方式

| 文件類型 | 網頁呈現 | 下載 |
|---|---|---|
| 作業流程（PDF／JPG） | 依時間點的泳道流程：階段 → 物業管理單位 → 回傳中心，可切換原始流程圖 | 原始文件 |
| 整備作業與應變計畫（A） | 依作業要項分組，標示每項要準備的資料 | 原始文件（需附照片，下載後填寫） |
| 重點檢核表（B） | 每項可點選二選一、填備註，有完成進度與「全部設為正常」 | 原始文件／已填寫版本 |
| 自主檢查表（C） | 每項可填寫檢查結果與缺失複查結果 | 原始文件／已填寫版本 |
| 災損報告表 | 點選 □ 項目即勾選（下載時變成 ■），可填說明欄位 | 原始文件／已填寫版本 |
| 事件表 | 事件類型可複選，可填歷程與處理措施 | 原始文件／已填寫版本 |

- 簽章、照片、空白底線欄位會在網頁上提醒「下載後手動填寫」。
- 填到一半的內容會自動暫存在那台電腦的瀏覽器裡，不會上傳到任何地方。

## 新增或修改內容

### 1. 修改既有文件
1. 用新版檔案覆蓋 `files/` 裡的同名檔案。
2. 如果是 Word 文件，執行 `python tools/build_data.py` 重新產生 `data/docs/` 和 `data/templates/`。
3. 如果是流程圖，更新 `assets/img/flows/` 的圖片，並調整 `data/flows.js` 裡可點擊熱區的座標（links 的 box）。
4. 章節卡片的滑過照片（目前為 Figma 生成的示意照，可換成實拍）：把照片（建議 1200×800 JPG、300KB 內）放到 `assets/img/covers/`，檔名對應 `data/catalog.js` 的 cover 欄位，例如 `NC-01-01.jpg`。

### 2. 新增子頁或大章節
1. 把新資料夾放進 `files/`（照「2.資料庫」的命名）。
2. 在 `data/catalog.js` 加入章節或子頁，以及每份文件的 `code`、`type`、`label`、`file`。
3. Word 文件：在 `tools/build_data.py` 的 `DOCS` 清單加一行並指定類型，再執行一次。
4. 新的版型（例如沒見過的表單格式）需要在 `assets/js/app.js` 加一個呈現方式。

> 需要 Python 3：`pip install python-docx lxml`

## 本機預覽

直接雙擊 `index.html` 就能開啟，所有功能都可以用（包括下載已填寫版本）。字型從 Google Fonts 載入，離線時會改用系統字型。
